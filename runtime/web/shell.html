Forget the saved game files

Select your own dump of the game (ULUS-10139). Files are read on this device and never uploaded.

Made by PPSSPP from your disc: Settings → Tools → Developer tools → “Dump decrypted EBOOT.BIN on game boot”, then start the game once; the file appears in PSP/SYSTEM/DUMP. It is translated into code for your browser right here, once, and kept in this browser.

Both files are then kept in this browser's own storage, on this device: next time you just press Play.
