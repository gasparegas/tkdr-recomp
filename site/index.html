The first time, the game (about 1 GB) is downloaded from this site's own server and kept in this browser: after that it starts right away, without downloading it again.

Bring your own dump of the game (ULUS-10139). Files are read on this device and never uploaded.

…or drop them anywhere on this page. The disc image can be an ISO or a CSO.

The EBOOT is the decrypted executable, made by PPSSPP from your disc: Settings → Tools → Developer tools → “Dump decrypted EBOOT.BIN on game boot”, then start the game once; it appears in PSP/SYSTEM/DUMP. It is translated into code for your browser right here, once.

Everything is then kept in this browser's own storage, compressed, on this device: next time you just press Play.
